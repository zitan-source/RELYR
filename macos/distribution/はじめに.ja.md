# RELYR for Mac — 無料試用版 0.2.0

キー・マウスのレイヤー、マクロ、Deckパネルを設定できるMacアプリです。利用料金・体験期限はありません。「試用版」は開発中であることを示し、有料への切替予定を意味しません。

## 対応するMac

Apple Silicon（M1・M2・M3など）搭載、macOS 13以降。画面左上のAppleメニュー →「このMacについて」で確認できます。Intel MacとWindowsではこのアプリを実行できません。対応OSすべての実機動作を保証するものではありません。

## 1. インストール

1. 公式リポジトリ https://github.com/zitan-source/RELYR のReleasesからMac用DMGを入手します。Windows用EXEは使いません。
2. DMGをダブルクリックして開きます。
3. 開いた画面の左側の **RELYR Mac Trial.app** を、右側の **Applications（アプリケーション）** フォルダへドラッグします。
4. アプリケーションフォルダ内のRELYRを開きます。コピー完了後、Finderのサイドバーから「RELYR Installer」を取り出してください。DMG内から直接使い続けないでください。

図解： `DMGを開く → 左のRELYRを右のApplicationsへドラッグ → アプリケーションから起動`

## 2. 初回にMacが起動を止めた場合

この試用版はAppleのDeveloper ID署名・公証を受けていません。Macが開発元を確認できない旨の警告を表示することがあります。

公式配布元から入手したアプリであることを確かめ、実行する判断をした場合に限り、次の手順で個別に許可してください。

1. 起動時の警告を閉じます。
2. **システム設定 → プライバシーとセキュリティ** を開きます。
3. RELYRがブロックされた旨の表示にある **このまま開く** を選び、Macの認証を行います。
4. 表示された確認内容を読んで開きます。名称や表示位置はmacOSによって異なります。

「マルウェア」「コンピュータに損害」「破損」など別の警告の場合は、同じ原因と決めつけず起動を中止してください。「このまま開く」がない場合も、セキュリティを無効化するコマンドは使わず、表示内容を添えて公式リポジトリに報告してください。会社・学校の管理されたMacでは管理者によって起動が禁止される場合があります。

Appleの説明：https://support.apple.com/ja-jp/102445

## 3. キー入力の操作を許可する

起動許可と、キー・マウスの操作許可は別です。初回の入力変換は停止しています。

1. 操作許可がない場合、RELYRの起動時に中央へ設定ガイドが開きます。「あとで」で閉じた場合は、画面上部の **macOSの操作許可を設定** から再開できます。
2. アプリ内の **macOSの許可設定を開く** を押します。
3. 開いたMacの設定一覧で **RELYR Mac Trial** をONにします。
4. RELYRに戻り、許可済みになったことを確認します。使う準備ができたら **有効にする** を押します。

図解： `起動時の設定ガイド → macOSの許可設定を開く → RELYRをON → RELYRに戻る → 入力を有効にする`

Mac設定の左側にある一般的な「アクセシビリティ」画面ではありません。OSによって項目名が異なるため、RELYR内のボタンから開いてください。一覧にない／ONでも認識されない場合は、RELYRの案内画面にある同名のヘルプを開き、「このアプリをFinderで表示」で対象を確認してください。

緊急停止：**Control ＋ Option ＋ Command ＋ Escape**。通常の停止はRELYR左下またはメニューバーから行えます。

## 4. 設定の持ち運び・再インストール

- 保存：**設定 → バックアップとヘルプ → 設定を書き出す…** からJSONを保存します。
- 復元：同じ場所の **設定を読み込む…** から、Mac版で書き出したJSONを選びます。Windows版の設定は読み込めません。
- 読み込みは現在の設定を置き換えます。元の設定は内部バックアップに退避します。
- 読み込み後は誤動作を防ぐため停止します。完了画面の **有効にする** で再開できます。
- アプリ・フォルダ・音声など、割り当てたファイル本体はJSONに含まれません。別のMacではファイルの配置やパスを確認してください。
- アクセシビリティ許可はJSONでは移行できません。移行先のMacで許可します。ログイン時の自動起動も設定画面で状態を確認してください。

## 5. 更新

自動アップデートは未対応です。

1. 念のため設定をJSONに書き出します。
2. RELYRのメニューバーメニューから **終了** します。設定画面を閉じるだけでは常駐を終了しません。
3. 新しいMac用DMGを開き、アプリケーションフォルダの旧RELYRを新しいアプリで置き換えます。更新のためにアンインストールはしないでください。
4. 新しいRELYRを開き、設定と入力状態を確認します。Macが許可の再確認を求めた場合は、手順3のアプリ内ガイドを使います。

## 6. アンインストール

1. 再び使う可能性がある場合は、先に設定をJSONに書き出します。内部バックアップも削除対象です。
2. **設定 → バックアップとヘルプ → RELYRをアンインストール…** を押します。
3. 削除対象を確認し、アンインストールを実行します。

入力を停止し、ログイン時の自動起動を解除して、実行中のアプリとRELYR専用設定・キャッシュ等をゴミ箱へ移動して終了します。エラーが出た場合は完了していません。移動済みの項目はゴミ箱に残ります。

書き出したJSON、ダウンロード済みDMG、登録したアプリ／ファイル、解凍済みファイル、別の場所にあるRELYRのコピーは削除しません。macOSが管理する操作許可や診断履歴は残る場合があります。必要ならMacの許可設定からRELYRの項目を削除してください。ゴミ箱は自動で空にしません。

## 現時点の検証範囲

DMGの整合性、同梱アプリの自動テスト、隔離した設定の書き出し・削除・再読込、削除対象の限定を検証しています。別のMacでのダウンロード直後の起動、実ユーザーのアンインストールから再インストール、ログイン項目・権限の一連の操作は未検証です。不具合報告の際はmacOSのバージョンと状況を添えてください。設定JSONには入力文字列やファイルパスが含まれるため、そのまま公開しないでください。

## 複数のMacユーザーで使う場合

同じMacの各ユーザーでRELYRを起動し、別々の設定・プロファイル・マクロ・Deckを使用できます。同じユーザーで二重起動しようとした場合は既存のアプリを使います。ログイン時の自動起動は各ユーザーで設定します。操作許可はmacOSが判定します。同じMacで既に許可したアプリは、別ユーザーでも許可操作なしで動作する場合があるため、新しいユーザーを作るだけでは未許可状態の検証にはなりません。ユーザー切替中は入力処理を一時停止し、戻ったときに再開する仕組みです。実際のユーザー切替をまたぐ入力動作は検証中です。

アプリケーションフォルダのアプリ本体は共有です。本体をアンインストールすると他のユーザーもそのコピーから起動できなくなります。削除されるRELYR設定はアンインストールを実行したユーザーのものだけで、他ユーザーの設定を検索・削除しません。
