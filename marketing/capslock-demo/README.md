# CapsLock layer demo

This zero-budget 60-second video explains one concrete RELYR use case: turning CapsLock into a temporary keyboard layer without code or extra hardware.

Build on Windows:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\marketing\capslock-demo\build-video.ps1
```

Output:

`marketing/capslock-demo/output/RELYR-CapsLock-layer-demo-60s.mp4`

The build uses only RELYR-owned screenshots and clips already stored under `marketing/website-source`. It adds no telemetry, product code, installer changes, or external dependencies.
