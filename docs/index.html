Actionをドラッグ。

グリッドと一覧表示は同じDeckを編集します。ボタンの並び、色、アイコン、透明度、表示動作まで一か所で調整できます。

  • 01複数ボタンをまとめて移動・着色

マクロも、マウスジェスチャーも。
キーやDeckから、すぐ呼び出せる。

記録した手順とジェスチャーは、キーやDeckへ同じActionとして割り当てられます。

MACRO RECORDER / 27 STEPS記録後も、順番と待機時間を編集。
MOUSE GESTURES / 5 DIRECTIONS移動方向と短押しを別々のActionへ。
