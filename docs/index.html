WHO RELYR IS FOR

AutoHotkeyやマクロキーボードで足りるなら、無理に替えなくていい。

RELYRは、コードを書き直さずに入力環境を組み替えたい人のための選択肢です。キー、マウス、ジェスチャー、Deckを同じActionから画面上で設定できます。

画面で設定を変えたい

RELYRが合うのは、次の操作をひとつの画面とAction一覧で管理したい場合です。

  • 押している間だけ有効になるキーレイヤー
  • キー、マウス、ジェスチャー、Deckへの共通Action
  • アプリ別プロファイルとローカル保存

TWO STARTER SETUPS

最初の価値を、2つの設定で確かめる。

大きな移行は不要です。普段の入力を残したまま、まず安全な操作をひとつだけ追加できます。

01 / SPACE + E

片手でエクスプローラーを開く

  1. Spaceレイヤーを選ぶ
  2. Eキーを選ぶ
  3. 「エクスプローラーを開く」を割り当てる
  4. 保存し、Spaceを押しながらEを押す
02 / WORK DECK

作業開始の操作をDeckへまとめる

  1. Deckエディターを開く
  2. EXEやショートカットを空き枠へドロップする
  3. Windows操作やPCモニターのActionを追加する
  4. 保存し、必要なDeckを表示する

空いている場所へ、
Actionをドラッグ。

グリッドと一覧表示は同じDeckを編集します。ボタンの並び、色、アイコン、透明度、表示動作まで一か所で調整できます。

  • 01複数ボタンをまとめて移動・着色

マクロも、マウスジェスチャーも。
キーやDeckから、すぐ呼び出せる。

記録した手順とジェスチャーは、キーやDeckへ同じActionとして割り当てられます。

MACRO RECORDER / 27 STEPS記録後も、順番と待機時間を編集。
MOUSE GESTURES / 5 DIRECTIONS移動方向と短押しを別々のActionへ。
