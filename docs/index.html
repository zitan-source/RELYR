Why RELYR

ショートカットを
覚えるのではなく、
置く場所を決める。

RELYRは、キーボードを別物に置き換えるアプリではありません。普段の入力はそのままに、押している間だけ使える操作面を重ねます。

手を大きく動かさず、いま使っているキーやマウスから、必要な操作へ直接つなげます。

01 / LAYERS

押している間だけ、キーの役割が変わる。

Space、CapsLock、右クリック、進む、戻る。使いやすいボタンをレイヤーキーにして、いつもの操作へもう一段を追加できます。

  • 通常入力には影響しない
  • レイヤーごとに個別設定
  • 全レイヤーへの一括割り当て

02 / VISUAL EDITOR

見たまま選び、その場で割り当てる。

JIS・US配列のメインキーボード、テンキー、ナビゲーション、カーソルキー、マウスをひとつの画面に整理しました。

  • キー・ショートカット・文字列
  • アプリ・ファイル・URL
  • マクロ・ジェスチャー・マウス操作

Deck panel

必要なものを、画面の上に並べる。

アプリ、素材、URL、画像、GIF、動画をボタンへ。用途ごとのDeckを作り、必要なときだけ呼び出せます。

01自由なレイアウト1×1から18×18まで
02画像・GIF・動画プレビューを保ったまま操作
03ピン留め / 自動非表示狭い画面でも邪魔をしない

One app

ひとつの割り当てから、
PCの操作へ。

KEY

キーとショートカット

単一キーから複数キーの組み合わせまで。

APP

アプリ・ファイル・URL

よく使う場所へ迷わずアクセス。

MACRO

マクロ

キーとマウスの流れを記録・編集・再生。

PROFILE

プロファイル

使用中のアプリに合わせて自動切り替え。

GESTURE

ジェスチャー

カーソルの方向へ操作を割り当て。

UTILITY

Windows操作と便利機能

仮想デスクトップや自動解凍もまとめて。

Local first

設定は、あなたのPCの中に。

RELYRは入力内容を外部サーバーへ送信しません。設定とマクロはローカルに保存し、マクロ記録もユーザーが開始した間だけ動作します。

LOCAL

外部送信なし

操作設定はPC内で完結します。

RECOVERY

バックアップと復元

カスタマイズした環境を保存できます。

STOP

緊急停止

Ctrl + Alt + Shift + F12で入力処理を停止。

OPEN

ソース公開

MIT License。SHA-256も配布します。
