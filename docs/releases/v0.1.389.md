## English

<!-- RELYR-RELEASE-NOTES:en-US -->
This release prepares RELYR for reliable installation and removal through Windows package managers.

- Supports unattended uninstallation without blocking on a confirmation dialog
- Preserves user settings and diagnostics by default during unattended removal to prevent accidental data loss
- Adds an explicit `/VERYSILENT /PURGEUSERDATA=1` option for unattended complete removal
- Documents retained data and its storage locations in the README and privacy page
- Adds build-time protection so future installers cannot lose the unattended-removal behavior
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
Windowsのパッケージ管理ツールからも安全にインストール・削除できるようにするための更新です。

- 無人アンインストール時に確認画面で停止しないよう対応
- 意図しない消失を防ぐため、無人削除ではユーザー設定と診断情報を標準で保持
- 無人実行で完全削除するための`/VERYSILENT /PURGEUSERDATA=1`オプションを追加
- READMEとプライバシーページに、保持されるデータと保存場所を明記
- 今後のインストーラーから無人削除対応が抜けないようビルド時検査を追加
<!-- /RELYR-RELEASE-NOTES -->

For a new installation, use `RELYR-Setup-0.1.389.exe`. If RELYR is already installed, use the in-app updater or `RELYR-Update-0.1.389.exe`. SHA-256 checksum files are included for both installers.
