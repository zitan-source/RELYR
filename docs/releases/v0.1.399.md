## English

<!-- RELYR-RELEASE-NOTES:en-US -->
This update makes large Decks open and respond faster while restoring reliable button-name visibility.

- Fixed Deck button names becoming unreadable on the dark panel when an assigned button used a dark contrast text color.
- Deck name, file, icon, color, monitor, and Action changes now refresh only the affected cells instead of rebuilding the entire grid.
- Deck right-click menus are now created on first use, avoiding hundreds of invisible menu trees during startup.
- File thumbnails and application or shortcut icons are prepared without blocking the Deck's first visible frame.
- Removed redundant full-grid visual passes after assigning an Action to a Deck button.
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
大きなDeckの起動・操作を軽量化し、ボタン名が確実に読めるよう修正しました。

- 割り当て済みボタンの文字色が暗色になった際、暗いパネル上でDeckボタン名が見えなくなる問題を修正しました。
- Deckの名前、ファイル、アイコン、色、モニター、Action変更時に、グリッド全体ではなく対象セルだけを更新するよう改善しました。
- Deckの右クリックメニューを初回使用時に生成し、起動時に数百個の非表示メニューを作る処理をなくしました。
- ファイルのサムネイルやアプリ・ショートカットのアイコンを、Deckの初回表示を止めずに準備するよう改善しました。
- DeckボタンへActionを割り当てた後に発生していた、重複する全セル描画を削減しました。
