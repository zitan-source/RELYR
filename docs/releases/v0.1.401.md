## English

<!-- RELYR-RELEASE-NOTES:en-US -->
This update makes large Decks faster and more reliable, and makes recorded macros easier to edit and read.

- Fixed typed text being vertically clipped in the Deck button-name dialog and restored reliable button-name visibility on dark Deck panels.
- Moving, naming, assigning, recoloring, or otherwise changing a Deck button now refreshes only the affected cells instead of rebuilding the entire grid.
- Deck right-click menus and file or application previews are prepared without blocking the first visible frame, and drag feedback reuses the already-rendered button.
- Apply one delay value to multiple selected macro steps in a single operation.
- Apply one delay value to every step in the current macro with the new bulk command.
- Each bulk delay change is recorded as one Undo operation.
- Key and mouse Down events now show a green `↓ Press` badge, while Up events show a yellow `↑ Release` badge.
- Added matching labels for every supported display language without changing existing macro playback data.
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
大きなDeckの動作と表示の信頼性を改善し、記録したマクロをより簡単に編集・確認できるようにしました。

- Deckボタン名ダイアログで入力文字が縦方向に切れる問題を修正し、暗いDeckパネルでもボタン名を確実に読めるようにしました。
- Deckボタンの移動、名前、割り当て、色などを変更した際、グリッド全体ではなく対象セルだけを更新するよう改善しました。
- Deckの右クリックメニューとファイル・アプリのプレビューを初回表示を止めずに準備し、ドラッグ表示には描画済みのボタンを再利用するよう改善しました。
- 複数選択したマクロ手順へ、同じ待機時間を一度に適用できます。
- 新しい一括操作で、現在のマクロの全手順へ同じ待機時間を適用できます。
- 待機時間の一括変更は、1回のUndoでまとめて元に戻せます。
- キーとマウスのDownには緑の「↓ 押す」、Upには黄色の「↑ 離す」バッジを表示します。
- 既存のマクロ再生データを変更せず、すべての対応表示言語へ同等のラベルを追加しました。
