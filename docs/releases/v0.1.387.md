## English

<!-- RELYR-RELEASE-NOTES:en-US -->
This release makes the post-update notes suitable for worldwide distribution.

- Japanese app settings show the release notes in Japanese
- Every other supported language shows the release notes in English
- The update heading and confirmation button remain localized in each language
- Corrected malformed update-window translations in Chinese, Korean, French, and German

For a new installation, use `RELYR-Setup-0.1.387.exe`. If RELYR is already installed, use the in-app updater or `RELYR-Update-0.1.387.exe`. SHA-256 checksum files are included for both installers.
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
アップデート後のリリースノートを、世界向けの表示に対応したリリースです。

- アプリの言語が日本語の場合、リリースノートを日本語で表示
- 日本語以外の対応言語では、リリースノートを英語で表示
- 更新画面の見出しと確認ボタンは、各言語へのローカライズを維持
- 中国語・韓国語・フランス語・ドイツ語の更新画面にあった不正な翻訳を修正

初めてインストールする場合は `RELYR-Setup-0.1.387.exe`、インストール済みの場合はアプリ内更新または `RELYR-Update-0.1.387.exe` を使用してください。両方のインストーラーにSHA-256確認用ファイルを添付しています。
<!-- /RELYR-RELEASE-NOTES -->
