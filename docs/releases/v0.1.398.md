## English

<!-- RELYR-RELEASE-NOTES:en-US -->
This update makes Deck browsing, placement, and file organization faster and more predictable.

- File buttons now use the original file name as their default editable label without changing the source file or path.
- Added independent per-Deck options to hide all labels and to show or hide file extensions. Extensions are hidden by default, and custom labels remain unchanged.
- Improved video preview placement and pointer travel: previews stay close to their source, remain reachable, and yield immediately when browsing covered video buttons in the same row.
- Cursor-positioned Decks now center on the pointer while remaining fully inside the current screen, and shortcut explanations stay near their source button.
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
Deckでの素材選択・表示位置・ファイル整理を、より素早く予測しやすい動作に改善しました。

- ファイルボタンの初期ラベルに元のファイル名を使用します。ラベルは編集でき、元ファイル名やパスは変更しません。
- Deckごとに「ラベルを隠す」と「ファイルの拡張子を表示」を個別設定できるようにしました。拡張子は初期状態で非表示で、手動ラベルは設定の影響を受けません。
- 動画プレビューを素材の近くに表示し、プレビューまで移動しやすくしました。同じ行でプレビューに隠れた動画へ移動した場合も、即座に対象を切り替えます。
- マウス位置へ表示するDeckはポインターを中央に置きつつ画面内へ収め、ショートカット説明も元ボタンの近くに表示します。
