## English

<!-- RELYR-RELEASE-NOTES:en-US -->
Fix installation failures when registering the elevated launcher task (issue #13).

- Setup and Update now write the task definition as UTF-8 and escape XML characters, preserving accented characters, Japanese text, and ampersands in installation paths.
- The launcher task identifies the Windows account by its SID instead of an unqualified account name.
- If Windows still rejects task registration, Setup records its diagnostic output in the installation log and shows an English error on non-Japanese Windows installations.
- Existing settings, mappings, profiles, and Deck layouts are preserved.
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
管理者起動タスクの登録時にインストールが失敗する問題を修正しました（Issue #13）。

- 通常版・更新版ともにタスク設定をUTF-8で保存し、XMLの特殊文字を適切に変換することで、保存先に含まれるアクセント付き文字、日本語、アンパサンドを保持します。
- 起動タスクのWindowsアカウントを、修飾されていないユーザー名ではなくSIDで指定するようにしました。
- Windowsがタスク登録を拒否した場合は、その診断内容をインストールログに記録し、日本語以外のWindows環境では英語のエラーを表示します。
- 既存の設定、キー割り当て、プロファイル、Deckレイアウトは維持されます。
