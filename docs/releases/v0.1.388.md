## English

<!-- RELYR-RELEASE-NOTES:en-US -->
This hotfix restores consistent Deck icons for configurations created by earlier RELYR versions.

- Restores number icons for existing direct virtual desktop actions
- Restores full-size executable icons for existing app launch buttons, including GIMP and Copilot
- Preserves icons that users selected manually
- Remembers when a user explicitly selects no icon
- Adds regression tests to prevent updates from silently changing existing Deck appearance again

This update does not rewrite existing Deck actions, colors, names, or layout.
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
以前のRELYRで作成した設定に対し、Deckアイコンを正しく表示するための緊急修正版です。

- 既存の仮想デスクトップ直接切替に番号アイコンを復元
- GIMPやCopilotなど、既存のアプリ起動ボタンに実行ファイル由来のアイコンを適切な大きさで復元
- ユーザーが手動で選択したアイコンを維持
- ユーザーが明示的に「アイコンなし」を選択した状態を記憶
- 今後の更新で既存のDeck表示が意図せず変わらないよう回帰テストを追加

この更新は、既存のDeckのアクション、色、名前、配置を書き換えません。
<!-- /RELYR-RELEASE-NOTES -->

For a new installation, use `RELYR-Setup-0.1.388.exe`. If RELYR is already installed, use the in-app updater or `RELYR-Update-0.1.388.exe`. SHA-256 checksum files are included for both installers.
