## English

<!-- RELYR-RELEASE-NOTES:en-US -->
Fixed dragging assigned Actions from the right-hand pane.

- Clicking TAP or HOLD Action text no longer dismisses the selected key before dragging can begin.
- Added a regression test covering parent-window mouse-down handling for both Action cards.
- This release also corrects the missing bilingual release notes from v0.1.393. Japanese UI displays Japanese notes; other supported UI languages display English notes.
<!-- /RELYR-RELEASE-NOTES -->
