## English

<!-- RELYR-RELEASE-NOTES:en-US -->
This update fixes Deck name entry and removes the visible pause when moving configured buttons, while retaining the earlier large-Deck performance improvements.

- Fixed typed text being vertically clipped in the Deck button-name dialog; the field is now taller, vertically centered, and uses the active theme's text color.
- Moving a configured Deck button to a neighboring slot now reuses the existing grid and refreshes only the affected cells instead of rebuilding up to 324 cells.
- Deck drag feedback now reuses the already-rendered button instead of extracting its icon or decoding its thumbnail again when dragging begins.
- Deck name, file, icon, color, monitor, and Action changes refresh only the affected cells, and right-click menus are created only when first opened.
- File thumbnails and application or shortcut icons are prepared without blocking the Deck's first visible frame.
<!-- /RELYR-RELEASE-NOTES -->

## 日本語

<!-- RELYR-RELEASE-NOTES:ja-JP -->
Deckの名前入力を修正し、登録済みボタンを移動した際の一拍遅れる動作を解消しました。これまでの大きなDeck向け軽量化もすべて含まれます。

- Deckボタン名ダイアログで入力文字が縦方向に切れて見えない問題を修正しました。入力欄を高くし、文字を縦中央に配置して、現在のテーマの文字色を確実に使用します。
- 登録済みDeckボタンを隣の枠へ移動する際、最大324セルのグリッド全体を作り直さず、既存セルを維持して変更した箇所だけを更新するよう改善しました。
- ドラッグ開始時は表示済みのボタンをプレビューに再利用し、アイコン抽出やサムネイル再読込を行わないよう改善しました。
- Deckの名前、ファイル、アイコン、色、モニター、Action変更時は対象セルだけを更新し、右クリックメニューは初回表示時だけ生成します。
- ファイルのサムネイルやアプリ・ショートカットのアイコンを、Deckの初回表示を止めずに準備するよう改善しました。
