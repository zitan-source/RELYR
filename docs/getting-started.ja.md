# RELYRを3分で始める

[English](getting-started.md) | [日本語](getting-started.ja.md)

通常の文字入力を変えずに、Spaceレイヤーへ簡単な操作を1つ設定します。

## 1. 準備

- Windows 10または11 x64を使用します。
- AutoHotkey、PowerToys Keyboard Manager、メーカー製の割り当てソフトを一時的に無効にします。
- 緊急停止キー`Ctrl + Alt + Shift + F12`を覚えておきます。
- [公式の最新版](https://github.com/zitan-source/RELYR/releases/latest)から`RELYR-Setup-<version>.exe`をダウンロードします。
- 対応する`.sha256`ファイルがあることを確認します。公開ベータ版はコード署名前のため、Windowsに不明な発行元と表示される場合があります。配布元とチェックサムを確認できない場合は実行しないでください。

## 2. インストールして起動する

Setupインストーラーを実行し、表示される利用条件を確認して同意し、表示言語を選択します。インストール後、スタートメニューからRELYRを起動します。

管理者権限で動くウィンドウも操作できるように、RELYRは管理者権限のスタートアップタスクを作成する場合があります。これにより、起動のたびにUACを表示せずに動作できます。

## 3. 最初のレイヤー操作を作る

1. 左側の一覧から**Space**レイヤーを選択します。
2. 中央のキーボード画面で、使用していないキーを選びます。
3. 右側のパネルから、メモ帳の起動など安全なActionを選び、対象キーへ割り当てるかドラッグします。
4. 設定を保存します。

最初は安全なActionを1つだけ設定してください。基本動作を確認するまでは、シャットダウン、削除、スクリプト、長いマクロを割り当てないでください。

## 4. 動作を確認する

1. Spaceを普通に押して離し、空白が入力されることを確認します。
2. Spaceを押したまま、割り当てたキーを押します。
3. 設定したActionが1回だけ実行されることを確認します。

Actionが2回動く、またはキーが押されたままに見える場合は、緊急停止キーを押し、他の割り当てソフトを無効にしてから再確認してください。

## 5. 変更または削除する

Spaceレイヤーへ戻り、割り当てたキーを選択してActionを変更または削除します。変更後はもう一度保存します。

CapsLockレイヤーだけは扱いが異なります。有効化するとWindowsのキー割り当てが変更され、再起動が必要です。通常のCapsLock動作は、RELYRの設定またはアンインストーラーから復元できます。

## 6. 更新と問題報告

インストール済みのRELYRは、アプリ内から軽量な更新用インストーラーを取得できます。初回に利用条件へ同意済みの場合、通常の更新では同じ画面を再表示しません。

再現可能な問題は[不具合報告フォーム](https://github.com/zitan-source/RELYR/issues/new?template=bug_report.yml)からお知らせください。ログや画像を添付する前に、パスワード、非公開マクロ、個人情報を削除してください。詳しい確認事項は[サポート案内](../SUPPORT.ja.md)にあります。
