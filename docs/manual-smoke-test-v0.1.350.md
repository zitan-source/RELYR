# RELYR v0.1.350 実機確認チェックリスト

不具合があった場合は、チェック番号、操作手順、期待結果、実際の結果、使用アプリ、可能ならスクリーンショットを記録する。

## 事前確認

- [ ] 必要なら現在の設定をエクスポートまたはバックアップする。
- [ ] Update版で既存環境を更新し、タイトルまたは設定画面が `v0.1.350` になっている。
- [ ] 更新前のプロファイル、割り当て、マクロ、Deck、一般設定が残っている。
- [ ] RELYRが二重起動せず、通知領域のアイコンも1個だけ表示される。

## P0: 今回必ず確認する項目

### 1. 右クリックメニュー

- [ ] ダークモードで、割り当て済みの通常キーを右クリックする。区切り線が白くなく、背景になじむ細い線になっている。
- [ ] ライトモードでも同じメニューを開き、区切り線と文字が読める。
- [ ] 未割り当てキー、複数選択、Deckボタンでも右クリックメニューの外観が統一されている。
- [ ] Deckのファイル登録済みボタンで、名前変更、ファイル操作、色、アイコン、削除を含む長いメニューを開いて確認する。
- [ ] 無効な項目は無効表示、削除項目は危険色で表示され、クリック動作も以前と同じである。
- [ ] メニューを連続して開閉しても、位置ずれ、透明なクリック妨害領域、強制終了が発生しない。

### 2. JIS／US表示

- [ ] ダークモードで、キーボードアイコンが `JIS` の文字高中央に見える。
- [ ] ライトモードでも同じ位置に見える。
- [ ] JISとUSを切り替え、キーボード配列と割り当てが正常に切り替わる。

### 3. 通常入力とレイヤー

- [ ] 普通の左クリックがRELYRに奪われず、クリックとドラッグが通常どおり動く。
- [ ] 通常、Space、CapsLock、右クリック、戻る、進むの各レイヤーで、既存のキー割り当てが1回だけ実行される。
- [ ] レイヤーを押しながら未割り当てのマウスボタンをクリックしても、通常クリックが失われない。
- [ ] 入力後にCtrl、Shift、Alt、マウスボタンが押しっぱなしにならない。

### 4. 修飾キークリック／ドラッグ

- [ ] Shift＋左クリックの短いクリックが正常に動く。
- [ ] Shift＋左ドラッグが正常に動き、離した瞬間に終了する。
- [ ] Ctrl＋左クリックの短いクリックが正常に動く。
- [ ] PowerPointでCtrl＋左ドラッグによる図形コピーが正常に動く。
- [ ] 操作後に左ボタンまたは修飾キーが押しっぱなしにならない。

### 5. プロファイル

- [ ] プロファイルを手動切替すると、編集対象と実行割り当てが正しく切り替わる。
- [ ] アプリ自動切替が前面アプリだけに従い、別ウィンドウへ移動すると元へ戻る。
- [ ] RELYRの設定画面を開いても、無関係なアプリのプロファイルが残らない。

### 6. Deck

- [ ] Deck編集画面で名前、色、アイコン、ファイル、割り当てを変更すると、表示中Deckへ即時反映される。
- [ ] 表示中Deckで変更した内容が編集画面へ即時反映され、再起動後も残る。
- [ ] Deckの並べ替え、ファイルドロップ、自動非表示、端への折りたたみ、ピン、サイズ変更が以前と同じに動く。
- [ ] Deckを閉じたあと、背後のアプリをクリックでき、透明な妨害領域が残らない。

## P1: 一通り確認する項目

- [ ] マクロの作成、保存、再生、停止が正常に動く。
- [ ] ZIP、7Z、TAR.GZの自動解凍と進捗表示が正常に動く。
- [ ] 通知領域メニューがライト／ダーク両方で読め、表示、エンジン切替、再起動、終了が動く。
- [ ] 設定を保存してRELYRを再起動し、プロファイル、割り当て、Deck、マクロ、テーマが保持される。
- [ ] RELYRを終了するとフック、Deck、通知領域アイコンが残らない。
- [ ] Setup版を新規環境で使用する場合、.NET Runtimeを含めてインストールと初回起動が完了する。
- [ ] アンインストール時に、設定を残す選択と完全削除の選択が表示される。
